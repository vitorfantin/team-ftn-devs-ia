# team-ftn-devs-ia
Template de governança sênior para o time FTN DevsIA utilizando Spec-Driven Development. Inclui 8 agentes especialistas configurados, micro-workflows modulares de CI/CD, barreira rígida de testes (TDD >90%), automação de QA via qa-id e proteção de infraestrutura de borda com Traefik e Docker Swarm.
